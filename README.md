# AI Resume Analyzer

An AI-powered Resume Analyzer built using Python, Streamlit, Ollama, and Local Large Language Models.

## Features

- Upload Resume PDF
- ATS Score
- Resume Summary
- Strengths & Weaknesses
- Missing Skills
- Improvement Suggestions
- Suitable Job Roles
- Interview Questions

## Tech Stack

- Python
- Streamlit
- Ollama
- PyPDF2
- Qwen / Gemma

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
